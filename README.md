# Tabla periódica 4º ESO

App para repasar la tabla periódica en el móvil: tabla interactiva, fichas, test con 7 tipos de pregunta y seguimiento del progreso.

Se publica con GitHub Pages: https://indalo-apps.github.io/tabla-periodica/

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar un test ni un mazo de fichas a medias.
